# रिक्षा मित्र (Ride Mitra) — वापरकर्ता मार्गदर्शिका (Marathi)

## १. विद्यार्थ्यांसाठी (Student Guide)
1. **लॉगिन:** तुमचा १० अंकी मोबाईल नंबर टाका आणि एसएमएस द्वारे आलेला ओटीपी प्रविष्ट करा.
2. **रिक्षा बुक करणे:**
   - पिकअप थांबा (उदा. लावेल हायवे किंवा स्टेशन) आणि ड्रॉप थांबा (जीआयटी कॉलेज किंवा हॉस्टेल) निवडा.
   - नक्की भाडे आधीच स्क्रीनवर दिसेल. कसलीही घासाघिस करण्याची गरज नाही.
   - प्रवासी संख्या आणि फुल रिक्षा किंवा शेअरिंग रिक्षा निवडा.
   - **"रिक्षा बुक करा"** वर टॅप करा.
3. **प्रवास ट्रॅकिंग:**
   - चालक नियुक्त झाल्यावर चालकाचे नाव, रिक्षा नंबर, फोन नंबर व नकाशावर लोकेशन दिसेल.
   - थेट चालकाशी फोनवर बोलण्यासाठी कॉल बटण वापरा.
4. **आपत्कालीन SOS:**
   - प्रवासादरम्यान काही अडचण आल्यास लाल **SOS** बटण दाबा. कॉलेज सुरक्षा कक्ष आणि प्रशासनास तात्काळ इशारा जाईल.
5. **रेटिंग देणे:** प्रवास पूर्ण झाल्यावर चालकास १ ते ५ स्टार द्या.

---

## २. रिक्षा चालकांसाठी (Driver Guide)
1. **नोंदणी:**
   - **"नवीन चालक नोंदणी"** वर जा. नाव, फोन नंबर, रिक्षा नंबर (उदा. MH 08 AB 1234) भरा. नोंदणी १००% मोफत आहे.
   - कॉलेज प्रशासनाकडून पडताळणी झाल्यावर खाते सक्रिय होईल.
2. **ऑनलाइन / ऑफलाइन:**
   - कामावर असताना मोठे **"कामासाठी ऑनलाइन व्हा"** बटण दाबा.
   - तुम्ही रांगेत किती नंबरवर आहात ते दिसेल (Fair Turn Queue).
3. **भाडे स्वीकारणे:**
   - नवीन फेरी आल्यावर मोठ्या आवाजात घंटी वाजेल. स्क्रीनवर पिकअप, ड्रॉप आणि मिळणारे भाडे दिसेल.
   - ३० सेकंदात **"स्वीकारा"** बटण दाबा.
4. **प्रवास पूर्ण करणे:**
   - पिकअपला पोहोचल्यावर **"मी पोहोचलो"**, विद्यार्थी बसल्यावर **"प्रवास सुरू करा"**, आणि प्रवाशानंतर **"प्रवास पूर्ण झाला"** दाबा.
   - प्रवाशाकडून पूर्ण रोख रक्कम घ्या. Ride Mitra कोणतेही कमिशन कापत नाही!
